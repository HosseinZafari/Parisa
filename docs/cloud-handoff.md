# تحویل نسخهٔ محلی به محیط کلود

این نسخه شامل داشبورد خواناتر با تم روشن و تاریک، اتصال قابل تنظیم مدل زبانی، راهنمای محصول و فروشنده، صف رسیدگی عادی و فوری، نمایش پیام‌های دستیار در پنل و اصلاح درخواست تغییر سفارش پس از پرداخت است.

## اجرا

پس از دریافت شاخه، با Python 3.11 یا جدیدتر و Node.js سازگار با Vite:

```sh
npm run setup
npm run dev
```

راهنمای کامل در README است. تنظیمات را از `.env.example` بسازید؛ اجرای پیش‌فرض با مدل، پرداخت و اینستاگرام آزمایشی و بدون کلید خارجی ممکن است. محیط کلود باید درگاه رابط ۵۱۷۳ و در صورت نیاز API روی ۸۰۰۰ را به روش مجاز همان محیط در دسترس مرورگر قرار دهد.

## داده و رازها

فایل محیط محلی، کلید مدل، توکن‌ها، پایگاه داده، پشتیبان‌ها و تصاویر آزمون داخل کامیت نیستند. برای محیط تازه پایگاه دادهٔ تازه ایجاد می‌شود. برای پایگاه موجود پیش از اجرا پشتیبان بگیرید و مهاجرت‌ها را با `python scripts/backend.py migrate` اجرا کنید؛ مهاجرت رسیدگی گفتگوها، پیام‌ها و سفارش‌های قبلی را حفظ می‌کند. بازنشانی دادهٔ موجود لازم نیست.

اطلاعات عمومی فروشگاه از بخش تنظیمات پنل و محصولات از مدیریت محصول قابل ویرایش‌اند. برای فعال‌کردن مدل واقعی، کلید و نشانی و نام مدل فقط روی بک‌اند تنظیم شوند؛ راهنمای `docs/mock-and-llm.md` را ببینید.

## وضعیت استقرار و آزمون

حساب متا متصل نشده و هیچ استقرار AWS یا Cloudflare انجام نشده است. AWS در مرحلهٔ احراز هویت و اطلاعات پرداخت حساب متوقف شد. محدودیت کاربر برای ادامهٔ استقرار، بدون کارت و بدون هزینه است. این نسخه برای اجرای محلی یا محیط کلود آماده است؛ سازگارسازی برای Cloudflare Workers هنوز انجام نشده است.

آخرین بررسی نسخه: ۸۷ آزمون بک‌اند موفق، بررسی Svelte بدون خطا و هشدار، ساخت Vite موفق. مسیر تغییر سفارش پرداخت‌شده از چت تا صف داشبورد نیز در مرورگر محلی آزمایش شده است. برای اجرای دوبارهٔ بررسی‌ها:

```sh
npm test
```
