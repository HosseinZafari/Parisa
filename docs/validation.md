# نتیجهٔ اعتبارسنجی محلی

تاریخ: ۴ نوامبر ۲۰۲۶. محیط بررسی: ویندوز، Python 3.13.9 و Node.js 24.20.0.

| بررسی | نتیجه |
| --- | --- |
| راه‌اندازی با `npm run setup` | موفق؛ ساخت محیط، نصب و مهاجرت |
| اجرای هم‌زمان سرور و رابط | موفق با `npm run dev` |
| آزمون‌های متمرکز بک‌اند | ۸۷ آزمون موفق |
| آزمون‌های مرورگر Chrome | ۶ آزمون متمرکز رابط موفق؛ سه مسیر پذیرش قبلی نیز موفق بودند |
| تحلیل Svelte | بدون خطا و هشدار |
| ساخت خروجی Vite | موفق |
| بررسی کد Python با Ruff | موفق |
| مهاجرت اولیه و ارتقای رسیدگی | موفق در پایگاه موقت؛ ارتقای محلی با پشتیبان و حفظ داده نیز موفق |
| بازنشانی دادهٔ نمایشی | موفق در پایگاه محلی ساخته‌شده برای پروژه |
| سلامت و حفاظت مسیرها | سلامت ۲۰۰ و مسیر فروشنده بدون نشست ۴۰۱ |
| قرارداد رابط | ۴۰ مسیر مستند و ۵۲ schema |
| ساختار Compose | نحو و نام سرویس‌ها بررسی شد |

آزمون مرورگر شامل سفارش فارسی، اصلاح تعداد، تکمیل نشانی، خلاصه، پرداخت آزمایشی، تکرار تأیید، تغییر و تأیید فروشنده، پرداخت تکمیلی، آماده‌سازی، ارسال، یادداشت پس از ارسال، پیگیری خصوصی و مدیریت محصول است. تصویر دسکتاپ، موبایل و گفتگو نیز بررسی شد.

اتصال واقعی `opencode-go/glm-5.3-flash` با نشانی اشتراکی `https://opencode.ai/inference/go/openai/v1` آزمایش شد. پاسخ اولیهٔ سرویس نوع مصرف را `go` گزارش کرد. آزمون خروجی ساختاریافته و مسیر کامل مرورگر با دادهٔ ساختگی شامل پیام طبیعی فارسی، اصلاح تعداد و اندازه، تکمیل نشانی، تأیید خلاصه و ایجاد سفارش در انتظار پرداخت موفق بود. مبلغ نهایی آزمایش ۹۹۰٬۰۰۰ تومان به‌صورت محاسبهٔ سرور و کاملاً آزمایشی بود. کلید در محیط محلی بک‌اند نگهداری می‌شود و در کد ردیابی‌شده یا خروجی رابط وجود ندارد. مدل‌های دیگر فقط به‌عنوان انتخاب قابل تنظیم مستند شده‌اند و زنده آزمایش نشده‌اند.

مسیر تازهٔ راهنمای محصول و پشتیبانی هم با همین مدل واقعی در مرورگر موفق بود: توضیح گزینه‌های بسته‌بندی و افزایش قیمت، حفظ انتخاب‌نشدن بسته‌بندی هنگام سؤال، انتخاب بعدی مشتری، سؤال دربارهٔ ساعت کاری، درخواست فروشنده، ارتقا به رسیدگی فوری، نمایش وظیفه در داشبورد و موبایل، رفتن از اعلان به همان گفتگو، نمایش پاسخ‌های دستیار و بستن رسیدگی همراه با فعال‌کردن دوبارهٔ دستیار. تصویرهای محلی این بررسی در `artifacts` ذخیره شده‌اند. در یک پاسخ واقعی، مدل اطلاعات سؤال را اشتباهاً در uncertain_fields گذاشت؛ این حالت برای سؤال شناخته‌شده و بدون اعمال تغییر سفارش بازیابی می‌شود و آزمون بازگشت دارد. پاسخ‌های نامعتبر دیگر همچنان با پردازش محلی جایگزین ادامه می‌یابند.

حساب اینستاگرام به دلیل نبود اعتبارنامه و مجوز، زنده آزمایش نشده است. اعتبار، طرح و هزینهٔ حساب AWS تأیید نشده و هیچ منبع ابری ایجاد نشده است. سرویس Docker روی این دستگاه فعال نبود؛ ساخت و اجرای تصویر کانتینر و صدور گواهی HTTPS باید روی میزبان استقرار بررسی شود.

مسیر تغییر پس از پرداخت از خودِ چت در مرورگر نیز بررسی شد: درخواست کلی، انتخاب مشخصه، توضیح یکسان‌بودن مقدار پیشنهادی با مقدار فعلی، انتخاب «کوچیک»، ثبت درخواست منتظر تأیید، حفظ اندازهٔ قبلی و نمایش سفارش در فیلتر درخواست تغییر داشبورد. تصاویر `paid-chat-change-pending.png` و `paid-change-dashboard.png` در `artifacts` هستند. آزمون‌های `test_chat_paid_changes.py` این مسیر را از پیام مشتری تا اعلان، صف فروشنده و تأیید تغییر پوشش می‌دهند.

هشدار غیرفعال‌شدن آیندهٔ یک نام قدیمی در وابستگی آزمون Starlette/AnyIO وجود دارد و آزمون‌ها را ناموفق نمی‌کند. بررسی وابستگی‌های ابزار توسعه در راهنمای آزمون مستند شده است.
